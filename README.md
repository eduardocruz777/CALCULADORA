# 🧮 Calc.js - Calculadora Avançada com JavaScript Moderno e Módulos ES6+

## 📌 Visão Geral do Projeto
O **Calc.js** é uma aplicação de calculadora científica e aritmética desenvolvida em JavaScript puro (Vanilla JS). O objetivo central deste projeto foi aplicar e consolidar conceitos profundos de manipulação dinâmica do DOM, tratamento de exceções, arquitetura de código modular baseada em arquivos especializados (`import/export`) e gerenciamento avançado de temas visuais (*Dark/Light Mode*).

Projeto prático desenvolvido durante a formação especializada em Engenharia Front-End da **OneBitCode**.

---

## 🛠️ Tecnologias, Recursos Lógicos e Engenharia de Software
* **JavaScript Moderno (ES6+):** Uso de funções modulares isoladas para manutenção do princípio de responsabilidade única do código.
* **Manipulação de DOM & Eventos:** Captura e processamento de interações em tempo real utilizando escutadores de eventos (`addEventListener`) acoplados ao teclado virtual e físico.
* **Lógica Computacional e Tratamento de Erros:** Implementação de rotinas de avaliação de expressões lógicas com prevenção e sinalização visual instantânea de erros de sintaxe matemática (classe `.error`).
* **API de Clipboard Nativa (`navigator.clipboard`):** Integração com o ecossistema do sistema operacional para permitir a cópia do resultado final para a área de transferência com feedback visual dinâmico de estado ("Copy" ➔ "Copied!").
* **Arquitetura CSS Moderna (Grid & Variables):** Estruturação do layout das teclas utilizando CSS Grid (`grid-template-columns`) e controle de paleta de cores centralizada através de variáveis nativas do CSS (`:root`).

---

## 📂 Organização Estrutural do Repositório
* `src/js/modules/`: Módulos JavaScript isolados (Cálculo, Temas, Teclado, Clipboard).
* `src/css/`: Folha de estilos centralizada utilizando variáveis customizadas e Grid System.
* `index.html`: Estrutura semântica e ponto de entrada da aplicação.
* `vite.config.js` / `package.json`: Configurações de empacotamento e scripts de build.
* `README.md`: Documentação técnica e de negócios do projeto.
